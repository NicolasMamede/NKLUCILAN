# NKLUCILAN Focus 3.4 — Detalhes e legibilidade

- Semana: toque/click em uma atividade, prova ou trabalho para visualizar título, matéria, data, horário e descrição/conteúdo. O botão **Personalizar cor** fica dentro do painel de detalhes.
- Mês: o comportamento é o mesmo, inclusive nos cartões mostrados abaixo do calendário no celular.
- Início: tarefas de Hoje e próximas provas abrem o painel de detalhes. O botão de concluir atividade permanece separado. As tarefas de Hoje possuem linhas divisórias mais evidentes no celular.
- Contraste: correções de textos na seleção de cores, campo de hexadecimal, títulos e rótulos no tema claro mobile. Desktop preservado.
- Os dados são lidos das consultas existentes do Supabase; nenhuma migração SQL é necessária.

## Publicação
Extraia o ZIP. Copie o conteúdo da pasta `NKLUCILAN-main` para a pasta clonada `NKLUCILAN-repo` sem apagar `.git`. Confira `git status` e publique com `git add .`, `git commit -m "Focus 3.4 - Detalhes e contraste"` e `git push origin main`.

Depois da publicação, feche e reabra o aplicativo instalado (atualização de cache v7).
